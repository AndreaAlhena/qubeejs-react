This page builds an article list backed by a Strapi API. Its query lives in the address bar —
`/articles?q=react&status=published&sort=title&page=2` — so a reload, a shared link and the back
button all show the same list.

## 1. Declare the list

A list is declared once, with `defineList` from `@qubeejs/core`: the driver, the resource, the URL
parameters it owns, and how its state becomes a query. Declare it at module level, in a file that
both your pages and your components import.

<Code code={articleList} lang="ts" title="src/articles/article-list.ts" />

- **Values are typed from the declaration.** `page` and `sort` have defaults, so they are always a
  `number` and a list of sorts; `q` and `status` have none, so they may be `undefined`.
- **The order of `params` is the order in the URL.**
- **`q` is kept exactly as typed**, because a search box shows it while the user types; `apply`
  trims it on the way to the API. [Search, debounce & pending state](/guide/search-debounce/)
  explains why that matters.

Every param, and the rules the URL follows, are documented with the core:
[Lists & URL state ↗](https://qubeejs.andreatantimonaco.me/guide/lists/).

## 3. Use the hook, and fetch

`useQubeeList` reads the URL into typed state and gives back the request for the page to show;
`useQubeeQuery` fetches that request and parses the answer with the driver that built it.

<Code code={quickStart} lang="tsx" title="src/articles/articles-page.tsx" />

What happens when someone types `react` into the search box:

1. `set({ q: 'react' }, { debounce: 300, replace: true })` updates `state.q` at once, so the input
   never lags behind the typing.
2. 300 ms after the last keystroke, the adapter navigates **once**, to `/articles?q=react`,
   replacing the history entry instead of adding one per keystroke. The page goes back to 1: a new
   search makes the old page number meaningless.
3. `request` changes — its `uri` now filters on the title — and `useQubeeQuery` fetches the new
   page. The rows of the old one stay on screen until it arrives.
