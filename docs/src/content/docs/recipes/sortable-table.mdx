## How it works

- `list.toggleSort(field)` exists because `articleList` declares exactly one `sortParam`, and `field`
  is typed to `'publishedAt' | 'title'` — the fields that param allows.
- A plain click makes the field the only sort: flipped when it was the primary sort, ascending
  otherwise — even if a secondary sort named it. `{ multiple: true }` (a shift-click) flips the field
  in place wherever it is, or appends it ascending, keeping the other sorts.
- The sort lives in the URL — `?sort=title`, or `?sort=-publishedAt,title` after a shift-click — and
  changing it goes back to page 1.
- `getAriaSort` gives the primary sort column its direction and every other column `'none'`.
- Headers stay `<th aria-sort><button type="button">`: the button is reachable from the keyboard and
  announced as a control.
