A search box whose query lives in the URL: the input follows every keystroke, the URL changes 300 ms
after the last one, and *Clear* is immediate.

<Code code={articleSearch} lang="tsx" title="src/articles/article-search.tsx" />

## How it works

- The input's value is `list.state.q` — the draft — so it follows every keystroke without waiting for
  the URL.
- `{ debounce: 300 }` holds the navigation until the typing pauses; `{ replace: true }` keeps the
  searches out of the back button's history.
- *Clear* calls `set` without a debounce: it goes out at once, taking any waiting keystrokes with it.
- `articleList` keeps `q` exactly as typed and trims it in `apply`, so spaces can be typed.
- `isPending` announces the search while it waits and while the navigation is under way (with the Next.js App Router, until the new page has arrived).
