## How it works

- The `'react-router'` import is React Router 7 and later; on v6.4+ the same hooks come from
  `'react-router-dom'`.
- `useSearchParams()` returns a `URLSearchParams`, which a `RouterAdapter`'s `search` accepts as it is.
- `navigate(href, { replace })` is all the list asks of any router. React Router's `navigate` may
  return a promise; the list does not wait for it.
- `<Link to={list.href(…)}>` navigates in place and keeps a real href, so no click handler is needed.
- Every component under the route reads the same URL, so each can call
  `useQubeeList(articleList, useReactRouter())`. The draft and `isPending` stay with the component
  that made a change — see [Lists in the URL](/guide/url-lists/).
