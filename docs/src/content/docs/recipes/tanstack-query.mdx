In a component under `QueryRoot`:

```tsx
const router = useBrowserAdapter();
const list = useQubeeList(articleList, router);
const { data, isFetching } = useArticlesQuery(list);
```

## How it works

- The key is `['articles', request.uri, request.headers]`. `request` is built from the committed
  state, so the key changes once per navigation — never for a keystroke still inside its debounce.
- `placeholderData: keepPreviousData` keeps the current page on screen while the next one loads, so
  the table does not flash empty.
- `signal` cancels a request TanStack Query no longer needs.
- `fetchPage` passes `response.headers` to `paginate`, so header-paginated drivers work too, and
  returns `toPlain()`: a plain object TanStack Query can share structurally between refetches.
- `list.isPending` covers the debounce and the navigation, `isFetching` the request. Dim the table
  for either.
